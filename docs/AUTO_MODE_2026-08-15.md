# Auto-mode — the operating contract (2026-08-15, owen)

Owen turned auto-mode ON at level **"Verify + build + push side branch auto"**
(`/auto-mode-setup`, 2026-08-15). This is the standing agreement for how a
session drives the fix→verify→ship loop **without** stopping for permission at
each step. It does NOT loosen any hard rule in `CLAUDE.md §House rules` — it
sits on top of them.

## What runs AUTOMATICALLY, no ask

1. **Compile** every edit through the Unity bridge (`Unity_RunCommand`).
2. **Verify** — run the affected benches, ONE AT A TIME (they clobber each
   other and the career save — measured), in play mode where needed:
   - `PlaytestBench` (drives real onClicks, asserts the rendered outcome) — the
     harness that catches the device-escape class. Run it across a device
     matrix when a UI/layout change is involved.
   - `TouchSmoke`, `CategoryBench`, `ReplayBench`, `ProgramBench`, and any bench
     whose surface the change touches. `EnlistLiveBench`/`ReturningPlayerBench`
     when a dev server is up (5099 or cloud dev), else note them as unrun.
   - **Fingerprint the career save every time**, mtime included (baseline md5
     `b12cdfdc36cf1eb88ccc6c9fb98dd55e`). A changed save is a STOP, not a note.
3. **TestFlight build** — bump the iOS build number, generate the Xcode project
   (`BuildIOS.Build`), `xcodebuild archive` → `exportArchive` (cloud-signed,
   team `BMLXB23PHU`, key `PG23GXN3RN`) → `altool --upload-app`. Confirm
   `RB_DEV_SERVER` is absent from the iOS defines before every build.
4. **Push** the branch to the dated **side branch** on `du6/robot-brawl`
   (token from `.gh_token.local`, redacted).

## What STOPS and asks first (hard checkpoints)

- **Server deploy to production** (`deploy_api.zsh`, migrations) — owen's call,
  ALWAYS. Auto-mode never deploys.
- **Push to `main`** — never automatic (curated history, non-fast-forward).
- **A red bench, or a career-save fingerprint that moved** — stop, surface it,
  do not build or push over it.
- Anything in `CLAUDE.md`'s Prohibited/permission list (deleting data,
  force-push, credentials). Force-push stays forbidden.

## Discipline carried from CLAUDE.md (unchanged)

- Back up before editing (`_claude_backups/<topic>__<file>`).
- Predict before measuring; run the control leg before believing a negative.
- Owner state is sacred; benches isolate `Career.Data`.
- `docs/` is a MIRROR of the frozen claude.ai Project — a change here should be
  echoed to owen so the Project copy does not go stale.

## Rationale

Seven TestFlight builds in one session, each a manual bump→build→archive→
export→upload→push, plus a run of device-caught UI escapes. Auto-mode moves
the mechanical loop off owen and puts the human checkpoint where it belongs:
production, `main`, and any red result — never the tenth identical build.
